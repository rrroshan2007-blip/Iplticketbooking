# IPL Ticket Booking 🏏

A modern, full-stack IPL Ticket Booking web application built with **React**, **Vite**, **React Router**, and **Supabase**.

## 🚀 Features

- **Home Page**: Welcome screen with quick navigation actions.
- **Matches Page**: Explore upcoming matches with reusable `MatchCard` components (RCB vs CSK, MI vs KKR).
- **Ticket Booking Form**: Real-time form state validation for Name, Number of Tickets, Stand, and Venue with live booking details preview.
- **Supabase Database Integration**: Stores bookings directly into PostgreSQL database hosted on Supabase.
- **Booking History**: View previous bookings in a responsive table.
- **Filter by Venue**: Retrieve and filter bookings based on selected stadium/venue.
- **Responsive Design**: Clean UI optimized for desktop, tablet, and mobile screens.

## 🛠️ Tech Stack

- **Frontend**: React (Vite)
- **Routing**: React Router DOM
- **Backend / Database**: Supabase (`@supabase/supabase-js`)
- **Styling**: Pure responsive CSS

## 📋 Database Schema

The application connects to the `public.bookings` table in Supabase:

```sql
create table public.bookings (
  id bigint generated by default as identity primary key,
  name text not null,
  tickets integer not null,
  stand text not null,
  venue text not null,
  created_at timestamp with time zone default now()
);
```

## 💻 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone <YOUR_REPOSITORY_URL>
   cd ipl-ticket-booking
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
